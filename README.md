# 🧠 Machine Learning & Optimization Tools From Scratch

## 📌 Overview
This repository contains a collection of machine learning and mathematical optimization algorithms implemented from scratch for educational and practical purposes.  

The goal is to deeply understand how core ML components work internally rather than relying solely on high-level libraries.

---

## 🚀 Features

### 🔹 Feature Selection
- Sequential Forward Feature Selection (SFS)
- Sequential Backward Feature Elimination
- Cross-validation based evaluation
- Compatible with classification and regression models
- Works with any Scikit-learn estimator

### 🔹 Optimization
- Lagrange Multiplier method for constrained optimization
- Supports multiple variables and multiple equality constraints
- Symbolic computation using SymPy
